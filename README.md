# 新エリー都の一生

『ゼンレスゾーンゼロ』の世界観を借りた、**非公式のファン作品**の人生シミュレーションです。
ランダムに生まれ、数年ごとの決断だけを選び、最期まで見届けます。
元ネタは「80億分の1」（https://1in8b.life/ja/）。

## 遊び方
ブラウザで https://omeletteak.github.io/eridu-life/ を開くと遊べます（スマホでも可）。

手元で動かす場合は、`eridu-life.html` をブラウザで直接開くだけで動きます（ライブラリ・ビルド不要）。

## 注意
- HoYoverse およびゼンレスゾーンゼロの公式とは関係ありません。
- 公式キャラクターの名前・画像・ロゴは使っていません。作中の数値はゲーム用の架空のものです。
- シーズン2第6章までの内容を前提にしています。ネタバレに触れる表現はスタート画面の「ネタバレあり」に切り替えたときだけ出ます。

## 開発
- `node tools/simulate.js` … 一括シミュレーション（寿命・死因などの集計）
- `node tools/choices.js` … 選択肢の総点検
- 詳しい構成は `CLAUDE.md` を参照
