# 旧都陥落の演出（js/ui.js・js/sim.js）

- 陥落に遭う年齢は 1〜60歳（`fallAge`、若いほど出やすい）。同じ1秒に生まれた4人も同じ年齢
- 年齢で選択肢が変わる。範囲の中：0〜9歳は「親の手を握る」の一択 / 10〜13歳は子どもの選択 / 14〜39歳はおとなの選択 /
  40歳〜は「家族を先に逃がす」（家族がいれば。いなければ「近所の人を連れて逃げる」）や「店を守ろうとする」。
  範囲の外：0〜9歳は一択 / 10〜13歳は「炊き出しを手伝う」など / 14歳〜は受け入れ・距離・探しに行く（店主は炊き出し）
- 陥落の時点で自分以外の家族がすでに消息不明になっている状況が 15%（`FAMILY_LOST_RATE`、`loseFamily`）。
  配偶者と子どもも消え、幸福が下がる。範囲の中は「家族の姿はもうどこにもない」（`D.fallAlone`）、
  範囲の外は「家族がその日旧都に出かけていて連絡がつかない」（`D.fallFarAlone`）。どの年齢にも専用の選択肢がある。
  その後は毎年 2% で家族の一人と再会する出来事がある。開発用は `&alone=1`
- 節目の決断（15/18/24/29/42/62歳）は、陥落や災害と同じ年に重なったら翌年以降に持ち越す（見出しは実際の年齢を出す）
- 陥落を生き延びた店主は店を旧都に残すので「商店街の店員」になる（`lostShop`）。42歳の転機では
  「もう一度、自分の店を開く」が出て、貯えを見て判断する
- 低い確率（`RARE`=15%）でだけ起きる展開：治安局の局員への裏稼業の誘い（来なければその年は何もない）／
  陥落で家族が消息不明になって3年以内の家族の決断で「長く付き合ってきた相手がいます」
  （ふだんは「家族の行方がわからないまま、気になる人とも距離を置いています」で、一緒に暮らせる見込みも下がる）
- 侵蝕の症状は、ホロウに関わる仕事か裏稼業なら「仕事を変える」、そうでなければ「ホロウから遠い地区へ引っ越す」
  （すでにそこなら「外出を控える」）。働いていない人は「我慢して働く」ではなく「様子を見る」
- 共生ホロウ災害は 10歳未満だと「大人に連れられて避難する」の一択
- 陥落前の42歳の引っ越し先は「エリー都・中心街」（まだルミナスクエアがないため）
- 治安局の局員は、住んでいる場所に関係なく総動員（`D.fallPolice`）。持ち場は指令で決まり、60%（`POLICE_FRONT`）が
  「エリー都に入り、避難誘導にあたれ」、残りが「新都の側で、避難民の受け入れと治安の維持にあたれ」。選べるのは
  指令に従うか背くかだけ。背くと、生き延びても治安局を去って商店街で働く（`leavePolice`）。背き方は状況で変わる
  （家族がいれば家族のもとへ / 範囲の中なら避難の列へ / 外なら招集に応じない / 後方の指令なら人を探しに旧都へ行く（範囲の中なら残る））。
  演出は住んでいる場所で決まる。開発用は `&police=1`
- 範囲の中（D.fall, alarm:"near"）と外（D.fallFar, alarm:"far"）で演出を分ける。以下は主に範囲の中の話
- 範囲の外：揺れ・明滅なし。途切れがちなラジオのテロップ、画面下端から盛り上がる遠くのホロウ（`.hollow.far`）、
  地元のスカイライン（紫の光）。決断のあとは避難民の流入で地区の治安・災害・曝露が少し悪化（`fallWitness`）。
  報告では「旧都の外にいた」と出る。転出スタンプはなし
- 決断中：警報テロップ・赤い明滅・揺れ・大きな題字（`startAlarm` / `stopAlarm`）。制限時間はなし
- ホロウ（`.hollow`）：決断中は画面の左下からゆっくり迫る。決断カードだけはホロウより手前に出す
  （そのため揺れは `.wrap` ではなく子要素ごとにかけている）。生き延びると縮んで消え、亡くなると画面全体を覆ってから最期の画面へ（`swallowAll`）
- スカイライン（`js/skyline.js` の `skylineSVG`）：右下に出生地区の街並みをホロウと向かい合わせに出す。住民番号をシードに毎回描く
  （towers=高層ビル / shops=住宅と店舗・電線 / port=九龍城砦風の密集した建て増し＋ガントリークレーン / zakkyo=密集した建て増しだけ /
  works=骨組みとタワークレーン / midrise=中層ビルと店舗 / hillside=海辺から上る斜面に段々の家・提灯の石段・背後の山（九份風。衛非地区・澄輝坪） /
  sparse=低い施設が点在＋細い塔とドーム / outer=バラックの貧民窟と給水塔 / camp=積んだプレハブとテント）。
  窓の灯りが順に消えていく。生き延びると遠ざかって消え、亡くなるとホロウに覆われる。
- 旧都の時代はセピアの配色（`body.era-old`）。生き延びると今の配色へゆっくり移る
- 生き延びると住民票に「転出」スタンプ、住所欄に「旧都 → 移り住んだ先」（仮設住宅 50% / 六分街 30% / 郊外 20%、`fallSurvive`）
- 陥落のあとの報告（`fallReport`）：自分と4人の選択と安否を一人ずつ出し、続けて「あの日、旧都にいた100人」の点を
  D.fall と同じ確率で一つずつ確定させる。生き延びた場合は「先へ進む」を押すまで年が進まない。陥落で亡くなった場合は最期の画面の下に出す
- 安否は陥落した時点の生死（`fallSurvived`）で出す。最期の画面では4人とも最後まで流したあとなので `alive` は使えない
- 同じ1秒に生まれた4人の陥落年齢は本人と揃える
