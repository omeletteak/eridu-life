# 方針と、時代・場所の設定

## 方針
- 数値はゲーム用の架空の統計。重い出来事も起こるが場面は描かない
- 公式キャラクターの名前・画像・ロゴは使わない。地名や用語（ホロウ、エーテリアス、シリオン、ボンプなど）までに留める
- ネタバレは標準では避け、スタート画面の「ネタバレあり」（`Eridu.spoiler`、localStorage に保存）でだけ出す。
  出すのは Ver3.3（シーズン3第4章）まで。それより先の情報は入れない。切り替えで変わるのは文だけで、
  確率や効果は変えない（運命と道が切り替えで変わらないように）。公式の人物の名前は「あり」でも出さない
- 讃頌会：困っている人に誘いが来る決断と、通う人の出来事（`D.cult`、docs/sim.md）。標準では表の顔
  （食事と寝床を用意する、ホロウを敬う怪しい集まり）だけ。「あり」では名前と、「始まりの主」をあがめ
  人はホロウと共に生きる形へ進むと説く非合法の教団で、人をホロウの外で動くエーテリアスに変えようとしていること

## 時代と場所の設定
地名と包含関係は pixiv百科事典「新エリー都」の「地理」の節を参考にした（https://dic.pixiv.net/a/新エリー都）。
- 新エリー都は、もともと旧エリー都の新開発地区の呼び名。陥落で旧都が飲まれ、生き残った住民は新都の側か郊外へ移った
- 六分街とルミナスクエアはヤヌス区の一画。澄輝坪と泅瓏囲（澄輝坪の真下の海蝕洞窟の下町）は衛非地区の町。
  出生地の名前は「ヤヌス区・六分街」「衛非地区・澄輝坪」の形で包含関係を出す
- 旧都陥落で飲まれた範囲＝零号ホロウ（陥落前のホロウは今よりずっと小さかった想定）。旧都の地区名はぼかす。
  「あり」では陥落のあとの報告に、ミネルヴァ区とプルートー区が飲まれ、14基の式輿の塔を爆破してできた大地溝で
  止まったことと、元凶とされた人物の報道（名前は出さない）を出す。出生地の名前は変えない
- ロスカリファ（旧都の上空に浮かぶ島。旧エリー都の時代からの空域機密特区で、住民の多くはボンプ）は、
  噂を聞く出来事として「あり」でだけ名前を出す。標準では「雲の切れ間の大きな影」。住める場所にはしない
- 避難民の仮設住宅はこの作品の独自の設定（公式の地名ではない）

|---|---|---|---|

- いまの時代に仮設住宅で生まれた人は必ず、ほかの街でも 20% は「親が旧都から逃れてきた人」
- 旧都陥落に関わった組織（防衛軍・雲嶽山）は、標準では名前を出さず役割だけ
  （範囲の中「制服の部隊が避難路を確保」、衛非地区の範囲の外「山の道場の人たちが避難民を受け入れ」）。
  「あり」で名前に切り替え、範囲の中では「一部の部隊が避難路とは別の方角へ急ぐ」（私的に動かされた部隊）も足す。
  衛非地区の範囲の外では、雲嶽山の一部が青溟剣の剣守を見つけるため、身寄りをなくした子どもたちを集めて
  剣に選ばせていたことも足す
- 陥落前の街について公式に分かっていることは少ない。陥落前から栄えていたと明言されているのは「澄輝坪」くらい。
  ほかの地名も陥落前からあったとは思われるが、ゲーム内の現在ほど栄えたのは陥落後と考える
- ストーリーの把握は Ver3.3（シーズン3第4章）まで
