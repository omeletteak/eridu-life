# シミュレーションの構成（js/data.js・js/sim.js）

## 構成
- `DISTRICTS`: 出生地区。wealth / exp(エーテル曝露) / crime / edu / med(医療) / dis(年間ホロウ災害率)、w と old は時代ごとの出生の重み、
  zone は旧都陥落の範囲の中(inside)か外(outside)か、sky はスカイラインの種類
- 医療と教育は今の住所（`p.d`）の値で効く。住民票に「医療 / 教育」の水準（`level`）を出す
  - med：死亡率とけがの重さに `careF`（1.3−0.6×med）をかける。5歳未満はもっと差が大きい。侵蝕の自然な抜けと、侵蝕の高額治療の効き目も med しだい
  - edu：学生の間の知識の伸び、15歳で進学校を目指したときの伸び、夜間の講座の出やすさ
  - 範囲の外で陥落を見届けると、避難民で病院が混み med が少し下がる（`fallWitness`）
- `JOBS`: 仕事。inc(年収・万ディニー) / eth(年間侵蝕) / haz(追加死亡率) / hap
- `newPerson(era,isPeer,placeId)`: 地区・人間かシリオンか・隠しパラメータのエーテル適性(apt)を抽選。
  placeId を渡すとその地区に生まれる（スタート画面の「生まれる場所」。既定はランダム。同じ1秒に生まれた4人はいつもランダム）
- 生まれる場所の選択は、元ネタの「80億分の1」と違ってあえて選べるようにしている。旧都陥落の重さを強調するため、
  陥落で飲まれる範囲かどうかは画面で明言しない（区切りも付けない）。代わりに `outlook`（医療・治安・曝露・災害から見た
  暮らしの見込み ◎○△✕。陥落は入れない）の良い順に並べ、範囲の中の街ほど長生きできそうに見えるようにする。
  陥落前の人は自分の街を「旧都」と呼ばないので、範囲の中の地区は「エリー都・中心街 / 下町 / 雑居街」と呼ぶ
- 陥落が起きるまでは、画面に「旧都」と出さず「エリー都」と書く（スタート画面の「エリー都陥落の前」、住民票の時代、
  陥落の日の決断の題「エリー都陥落」と本文・選択肢、範囲の外のラジオ）。陥落のあとに振り返る文は「旧都」のまま
  （死因「旧都陥落」、陥落のあとの報告、転出スタンプ、住民票の時代は陥落を過ぎたら「旧都陥落の前」）
- `decisionFor()` と `D`: 決断の発生条件と中身（15/18/24/29/42/62歳、侵蝕60超、ホロウ災害、旧都陥落）
- 決断には `key`（D の名前）、選択肢には `id`（`"key.名前"`。ラベルが状況で変わっても同じ）と型 `t` を付ける。
  型は `KINDS`（逃げる・助ける・探す・守る・分ける・待つ・閉ざす・委ねる / 安定・挑む・外れる・共に・ひとり・変える・続ける）。
  時代をまたいで選択を比べるのに使い、比べるときは `group` でまとめる（助けると探すは同じ組）。
  ID と型は共有した記録との互換のため追記だけにする（名前を変えたり消したりしない）。新しい選択肢には必ず付ける
- `EVENTS`: 年ごとのランダムな出来事（確率関数と効果）
- `step()`: 1年進める。収入、侵蝕、状態値、出来事、死亡判定（ゴンペルツ型の基礎死亡率 × 健康補正 + 仕事などの追加リスク）
- 侵蝕度100でエーテリアス化して死亡
- 同じ1秒に生まれた4人は同じ `step()` で並走し、決断はランダム（`autoChoose`）。最期まで流すのは `runToEnd()`
- 乱数は `Eridu.setRandom(fn)` で差し替えられる（sim.js 内は `R()` を使う）
- 前世の記録は localStorage に直近10件

## 運命と道（lab で使う。考え方は docs/world.md）
- `newPerson(era, isPeer, placeId, fate)` に fate を渡すと、生まれは fate から、1年ごとの乱数は fate と年齢から決まり、
  ほかの人の乱数と混ざらない（`use(p)` で流れを切り替える。sim.js の公開の入口では必ず先に `use(p)`）
- `p.route`（選択肢の ID の配列）があれば `autoChoose` はその道をたどる
- 画面の演出の乱数（`rnd`）は運命から引かない
- `E.VERSION` は動き（確率・効果・決断・乱数を引く順番）を変えたら上げ、`node tools/fate.js --golden` で答えを作り直す
  （lab では版が変わると新しいシーズン。上げ忘れは tools/fate.js が止める）

## 記録の差し込み口
- `Eridu.hooks`：born / said / pick / year。既定は空で、本編の動きは変えない
- 選択肢を当てるときは画面からもランダムでも `apply(p, dec, o)` を通す（`o.fx` を直接呼ばない。tools/choices.js は例外）
- `Eridu.meSource(era, place)` / `Eridu.peerSource(me)`（ui.js が見る）：あれば、本人と同じ1秒の人を先にそこからもらう
  （開発用の `?fall` では使わない）。本編ではどれも置かない
